## 概要

Closes #28

倒したうんちくんの仲間化結果を、戦闘後ガチャ画面のカメラ映像へ重ねる。抽選は完了済みの結果を表示するだけで、この画面ではやり直さない。

## 変更内容

- 背面カメラ（`getUserMedia`）をガチャ画面だけで起動し、離脱・unmount・結果表示で track を停止する
- 今回選んだ食事写真があれば、映像上へ投げ入れる見た目を出す
- 仲間化成功時だけ Poopm が這い出る。失敗時は再抽選できないことを出す
- 非対応・拒否・HTTP では静止背景の同等結果画面にフォールバックする
- 食事撮影カメラは同じ停止処理を `src/lib/user-media-camera.ts` に寄せた

便器の 2D 検出（#125）や WebXR（#130）は入れていない。子 Issue は親 Issue のコメントから辿れる。
