## 詳細

`acceptBowelLog` が排便の「次へ」と同じタップで `input.click()` する。画面マウントの `useEffect` ではユーザー操作が切れてピッカーが抑制されることがある。

```46:50:src/features/battle/components/battle-completion-flow.tsx
  function acceptBowelLog(log: BowelLog) {
    setBowelLog(log);
    setError(null);
    openPicker();
  }
```

食事保存が成功してバトル完了だけ失敗したときは `savedMealLogId` を残して再送する。選び直すと ID を捨てるので、失敗後に写真を変えると未紐付けの `meal_logs` が残る。MVPでは許容。

`getUserMedia` はこの画面から呼ばない。`MealPhotoPicker` は使っていない。
