## 作品制作のきっかけ（選択式）

「社会課題・身の回りの課題」系の選択肢を推薦。
根拠: 健康データは毎日取れるのに排便記録だけは続かない、という課題解決が企画の本質のため。
その系統の選択肢がなければ「面白いものを作りたかった」系でも成立する。

【こだわりポイント】
・「記録するためにゲームをするのではなく、遊んだ結果として健康ログが残る」逆転設計

【技術的アピール】
・Next.js 16 (App Router) + TypeScript + Supabase（認証/DB/Storage）+ Vercel

・バトルはサーバー権威：敵生成・個体値抽選・ガチャ抽選をサーバー側で確定、書き込みはdefiner RPCのみ
・DBスキーマ→TypeScript型を自動生成しCI/pre-commitの2段で再生成漏れを検出
・ESLintの許可リスト方式でデータアクセス経路を3箇所に強制（塞ぎ忘れのない境界設計）
