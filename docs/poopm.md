# うんちくん (poopm)

敵・仲間・図鑑に出るキャラクターの見た目ルール。ゲームループは [`IDEA.md`](./IDEA.md)、データは [`architecture.md`](./architecture.md) の `characters` を参照。

![うんちくんのデザインスケッチ。三段うずまきの胴体、棒状の手足、頭・目・口が可変で手足は固定](./assets/poopm-sketch.jpg)

遠くから見ても「うんちくん」だと分かるのは、**三段うずまきの胴体**と**細い棒状の手足**だけ。個体差は頭・目・口で出し、色は種族ごとのシグネチャとして固定する。

## 固定と可変

| 部位 | 扱い | ルール |
| --- | --- | --- |
| 胴体 | 固定 | クラシックな三段うずまき。顔は中段〜上段 |
| 手足 | 固定 | 線の腕と脚。手は3本指、足は楕円。個体ごとに変えない |
| 頭 | 可変 | 個体ごとに形が違う。帽子などのアクセサリも頭に含める |
| 目 | 可変 | 種類は閉じない（千差万別） |
| 口 | 可変 | 種類は閉じない（千差万別） |
| 色 | 種族で固定 | 茶色に限定しない。種族ごとに1色持ち、個体差には使わない |

個体の見た目は `種族（色） × 個体（頭・目・口）`。手足を変えて個性を出さない。

## パーツ例

閉じたマスタではない。実装の初期セットと、絵を揃えるときの基準。

| 部位 | 例 | 見た目 |
| --- | --- | --- |
| 頭 | シルクハット | 平らな頂にツバ |
| 頭 | 果物 | ヘタ付きの実が頭頂に乗る |
| 頭 | コック帽 | 高い白い帽子 |
| 頭 | アホ毛 | うずまきから1本だけ伸びる毛 |
| 頭 | 新芽 | 平らな頂に短い茎 |
| 頭 | ウェーブ | 頭頂が波打つ |
| 目 | キリッ | 内側に下がる鋭い目 |
| 目 | にっこり | 上向きの弧（閉じ目） |
| 目 | まつ毛 | 大きな目にまつ毛 |
| 口 | べろ出し | 大きな笑顔で舌が見える |
| 口 | への字 | 下向きの弧 |
| 口 | 歯並び | 四角い口に歯のグリッド |

既存シード（カレー・野菜・激辛・肉・バナナ・ヨーグルト・ふつう・ゴールド）はこの組み合わせの実例。色のルールは下の「個体差の決め方」を参照。

## 個体差の決め方

DBに見た目の列は持たない。シードからハッシュで決定的にパーツを選び、同じシードならいつ描いても同じ顔になる。

| 対象 | シード | 効果 |
| --- | --- | --- |
| 敵 | `battle_results.id` | バトルごとに違う顔。リロード・復元でも同じ顔 |
| 仲間 | `user_characters.acquired_from_battle_id`（なければ `user_characters.id`） | 倒した敵と同じ顔で仲間になる |
| 図鑑の種族代表 | `characters.id` | 種族として安定した代表顔 |

`acquired_from_battle_id` は `battle_results` の削除で null になる。フォールバックの `user_characters.id` で顔が変わりうる点は許容する。

ハッシュはクライアントだけで再現できる小さなもの（FNV-1a 程度）でよい。`hash("<part>:<seed>")` のように部位ごとに別の値を取り、頭・目・口の組み合わせに相関が出ないようにする。

実装では `appearanceForCharacter` を個体シードを受け取る形に変える想定。`PoopmFigure` は appearance を受け取るだけなので変更不要。

### 色

色は種族ごとに1つ固定する。食べ物との紐付けは自然なものだけに留め、属性と色の1対1ルールにはしない（カレー=オレンジ、ヨーグルト=白、ゴールデン=金はそのまま）。色をレアリティの表現に使う余地も残す。

### パーツを増やすとき

`hash % パーツ数` で index を取るため、パーツを追加すると既存個体の見た目が変わる。MVPのうちはこれを許容し、リリース時にパーツIDのセットを固定する。新パーツは `hat-g`・`eye-k` のように連番で ID を採り、`public/assets/poopm_parts/<部位>/` に置く。

## 描画

重ね順は奥から **胴体 → 手足 → 頭 → 口 → 目**。色は胴体の塗りだけに効く。

1枚絵は置かない。パーツをレイヤーとして重ね、アイドル（呼吸・まばたき・頭の揺れ）とバトル（ヒット・食事）は Framer Motion で部位ごとに動かす。Live2D Cubism と Rive は使わない。

シルエット優先。線は均一で細い。顔は胴体前面、頭アクセサリはうずまき最上段の上。手足を太くしたり服や靴を足したりしない。

後ろ姿は別パーツを描かない。目と口を消し、頭だけ左右反転する。胴体と手足はそのまま。

置き場・型・`characters.id` との対応は [`architecture.md`](./architecture.md) の「うんちくんの描画（poopm）」。
