# レベル

力士（うんちくん）はストーリーの取組に勝ってレベルが上がり、上がるたびにどの値を伸ばすかをプレイヤーが選ぶ。
強さ全体の中での位置づけは [`parts.md`](./parts.md)、ストーリーの段階は [`battle.md`](./battle.md) 3.5。

## 上がり方

- その力士が、ストーリーのその取組に**初めて勝ったとき**に +1。同じ取組の再戦では上がらない
- 別の力士で同じ取組に勝てば、その力士は上がる。控えを育て直す道として残す
- 負けても下がらない
- 章ごとに上限がある。上限に達したら、次の章へ進むまで上がらない

稼げる量はストーリーの取組数で頭打ちになり、勝った回数や遊んだ時間では増えない。
寝る前の長時間プレイを報酬で促さないためでもある（[`game-design.md`](./game-design.md) 5章）。

### ストーリーの進め方

- 未クリアの取組に挑めるのは、記録した日だけ（1日1番分。負けても権利は残り、勝つまで挑める）
- クリア済みの取組は、いつでも再戦できる（練習用。レベルは上のルールどおり）

記録は「進める権利」、勝ちは「進んだ証」として分ける。

## 伸ばす値を選ぶ

レベルが1上がるごとに1ポイント入り、次のどれかに振る。

| 値 | 1ポイント | 向く型 |
| --- | --- | --- |
| 押す力 | +1% | 突きで攻め切る |
| 体格 | +1% | 押されにくい。四つ |
| 粘り | +2% | 土俵際で耐えて、うっちゃりを狙う |
| 息の最大 | +2 | 手数を出し続ける |

- Lv 1〜16 で最大15ポイント。1つの値に全部振ると押す力・体格は +15%
- 振った結果は、個体値・パーツと掛け合わせたあと [`parts.md`](./parts.md) の補正の幅で頭打ちにする。
  幅を超える振り方は、確定前に「これ以上は効かない」と見せる
- 時間に効く値（パリィ受付・速さ）は選べない。わずかな差で読み合いの手応えが変わるため、パーツだけに任せる

| 段階（[`battle.md`](./battle.md) 3.5） | レベル上限（案） |
| --- | --- |
| 序盤 | 5 |
| 中盤 | 10 |
| 後半 | 16 |

### 新しく仲間にした力士

いまの章の下限のレベル（前の章の上限）で加わり、そのぶんのポイントを振れる状態で届く。
ガチャで引いた子が育て直しなしで使えるようにし、手持ちが固定されるのを防ぐ。

## 守ること

- **レベルとポイントはクライアントに書かせない。** definer RPC だけが書く。勝敗をクライアントが申告して上げられると、
  改造で強くなれる。PVP を見据えると、勝敗の確定はサーバー側に置く（[`battle.md`](./battle.md) 4.4）
