# レベル

うんちくんは**記録を続けた日数**で育つ。レースの着順や勝敗では育たない。ループの全体と、ズルを防ぐ理由は [`game-design.md`](./game-design.md)。

## ステータス

どのゲーム（レース・相撲）でも共通の3つ（案）。レースを基準に決め、相撲など他のゲームでは各ゲームの値に換算する。

| ステータス | レースでの効き（案） | 相撲への換算 |
| --- | --- | --- |
| 体力 | 最後まで速度が落ちない | 未決（[`battle.md`](./battle.md) の息・粘りあたり） |
| パワー | 加速・最高速 | 未決（押す力・体格あたり） |
| 技術 | コース取り・抜け出し | 未決 |

相撲で、時間に効く値（パリィ受付・速さ）を換算先にしない。わずかな差で読み合いの手応えが変わるため（[`parts.md`](./parts.md)）。

## 育ち方

翌日以降、最初にアプリを開いたときに、前日までの未反映の日をまとめて反映する（[`game-design.md`](./game-design.md) 2章）。

| 源 | 1日あたり | 振り先 |
| --- | --- | --- |
| 排便の記録 | 通常の日はNポイント、後入力・信頼度低の日は減らす | プレイヤーが3つから選ぶ |
| 食事の記録 | 1日1回分で頭打ち | 食品群で自動で決まる（例：野菜→体力、肉→パワー） |

- ポイントが入るのは、その日の**相棒1体**だけ。どの子を育てるかを選ぶ遊びにする。
  - 相棒は、その日の最初の記録の時点で決める。反映は翌日なので、記録のときにサーバーへ残しておく。
  - ガチャで新しく仲間にした子はLv1から。ただし対戦ではレベルを揃えるので、厳選した子はすぐ対戦に出せる。
- 何回記録しても1日分以上は増えない。数えるのは通算の記録日数で、途切れてもペナルティはない。
- 食事は**何を食べたか**で伸びる値が変わり、件数では増えない。いろいろ食べると面白いが、たくさん記録しても得はしない。
- 便の中身では何も変えない（[`game-design.md`](./game-design.md) 3章）。

## 対戦ではレベルを揃える

対戦では、ポケモンのLv50固定と同じように、レベルによる差をなくす。

- 振ったポイントの**合計を固定値に揃え、振り分けの比率だけを残す**（案）
- 差がつくのは、振り分けの比率、個体値、パーツの組み合わせ。強い個体を選び抜く（厳選する）遊びはここに置く
- 対戦以外（レース・相撲のNPC戦）では、続けた日数の分だけ強い

これは [`parts.md`](./parts.md) の「ガチャの運で強さが決まらないようにする」原則を、対戦では緩めることになる。個体値の幅（±5%）とパーツの補正の幅は残し、腕の差を超えないようにする。

## 守ること

- **レベルとポイントはクライアントに書かせない。** definer RPC だけが書く。日付の区切りと、1日分の反映もサーバーで判定する。端末の時計を変えたり、クライアントを改造したりして強くなれないようにする。
