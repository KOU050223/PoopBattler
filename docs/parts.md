# パーツと強さ

うんちくんの強さが何で決まるかと、パーツの仕様。ステータスと育ち方は [`level.md`](./level.md)、パーツの強化は [`merge.md`](./merge.md)、石とガチャは [`game-design.md`](./game-design.md) の2章。相撲での補正の差し込み口と判定のルールは [`battle.md`](./battle.md) の3章が正本。

## 強さの源泉

| 源 | 入手 | 効き |
| --- | --- | --- |
| 種族 | ガチャ | 得意な型。相撲では得意手・基礎値・覚えられる必殺手（[`battle.md`](./battle.md) 2.12・2.15）。強弱ではなく型の違い |
| 個体値 | ガチャで仲間にした時点で抽選 | 3つのステータスに ±5% |
| レベル | 記録を続けた日数（相棒1体だけ） | ポイントを3つのステータスに振る（[`level.md`](./level.md)） |
| パーツ | ガチャ。合成で強化 | 同じパーツでもゲームごとに効く値が違う |
| 腕 | プレイ | 相撲の読み・パリィ・うっちゃり。レースは自動なので効かない |

- **レアリティは強さの上限を変えない。** レアリティで変わるのは見た目と出やすさだけ。
- **対戦ではレベルを揃え、個体値とパーツで差をつける**（[`level.md`](./level.md)）。厳選の遊びはここに置くが、個体値もパーツも幅を小さく保ち、相撲では腕の差を超えないようにする。

## 個体値

DB の `hp` / `power` / `speed` を、3つのステータス（体力・パワー・技術）の個体値に当てる（案）。今のレアリティ別の値（[`web/battle.md`](../docsArchive/web/battle.md) の「個体値の抽選」）のまま持ち、使うときに倍率へ換算する。

```text
個体値倍率 = 1 + 0.05 × clamp((値 − 基準) / 振れ幅, −1, +1)
```

基準と振れ幅にはレアリティ別の値を使う（HP は12倍）。どのレアリティも ±5% に揃うため、既存の個体はデータ移行なしで使える。

## パーツ

### 枠

部位は**頭・手・足**の3つ。まわしは廃止した。

- 部位ごとに1つずつ付ける。パーツは手持ちの道具で、うんちくんの間で付け替えられる。
- 付け替えはレース・取組の外でだけ行う。補正は開始時に1回だけ計算する（[`battle.md`](./battle.md) 3.1）。
- マイナスの補正を持つパーツは作らない。下振れは個体値だけにする。
- 相撲には、ほかに**必殺手の枠**がある。種族が覚えられる必殺手から1つ付ける（[`battle.md`](./battle.md) 2.12）。パーツではなく相撲だけの設定。

### ゲームごとの効果

1つのパーツが、ゲームごとに別の効果を持つ。レースで強いパーツが相撲でも強いとは限らず、ゲームごとに組み合わせを考える遊びにする。

| パーツ（例） | 部位 | レース | 相撲 |
| --- | --- | --- | --- |
| かたい頭 | 頭 | 体力 +3% | 息の最大 +5 |
| バネの足 | 足 | スタートダッシュ | 粘り +4% |
| 鉄のげんこつ | 手 | パワー +3% | 押す力 +3% |

- 効果は「倍率や加算値を返すだけ」にする。各ゲームの判定の順番やルールそのものは変えない（[`battle.md`](./battle.md) 3.1）。
- 1つのパーツの効果は +2〜5% 程度で、合成で最大2倍まで伸びる（[`merge.md`](./merge.md)）。
- 相撲では、パーツの組み合わせで戦い方が変わるようにしたい（ベイブレードのように、組み合わせで型が変わる）。数値の補正だけで出すか、組み合わせの効果を足すかは未決。

### 相撲での補正の幅

[`battle.md`](./battle.md) 3.4 の式を次のように具体化する。

```text
補正   = 個体値倍率 × レベル倍率 × Π(パーツの倍率)  → 値ごとの幅で頭打ち
最終値 = 種族の基礎値 × 補正 + Σ(レベル・パーツの加算値)
```

頭打ちは最終値ではなく補正に掛ける。種族の基礎値（カレーの押す力 1.2 など）はすでに幅の上限近くにあり、最終値で切ると得意な種族ほど育成が効かなくなるため。

| 値 | パーツの部位（案） | 補正の幅 |
| --- | --- | --- |
| 押す力 | 手 | 0.9〜1.3 |
| 体格 | 足 | 0.9〜1.3 |
| 粘り | 足 | 1.0〜1.4 |
| 息の最大 | 頭 | 100〜130 |
| 息の回復 | 頭 | 1.0〜1.2 |
| パリィ受付 | 手 | 1.0〜1.1 |
| がっぷり連打係数 | 手 | 1.0〜1.1 |
| 熱の時間 | 頭 | 2.5〜3.0秒 |
| 速さ | ─ | 1.0 固定 |

- まわしが受け持っていた体格は足に、熱の時間は頭に移した。
- パリィ受付とがっぷり連打は、[`battle.md`](./battle.md) の推奨幅より狭くしてある。時間の差は読み合いの手応えを大きく変えるうえ、得意手の補正（受付 ×1.3、連打 ×1.25）とも重なるため。
- 速さは [`battle.md`](./battle.md) 5章で未決のため、当面は効かせない。
- ストーリー序盤でまだ出てこない仕組み（必殺・熱）に効くパーツは、効果なしにしてグレーで表示する（[`battle.md`](./battle.md) 3.4・3.5）。
