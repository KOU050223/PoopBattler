# パーツと強さ

うんちくんの強さが何で決まるかと、パーツの仕様。補正の差し込み口と判定のルールは [`battle.md`](./battle.md) の3章が正本で、ここは「何がどれだけ効くか」と入手の経路を決める。レベルは [`level.md`](./level.md)、パーツの強化は [`merge.md`](./merge.md)、ガチャを引ける回数は [`game-design.md`](./game-design.md) の3章。

## 強さの源泉

| 源 | 入手 | 効き |
| --- | --- | --- |
| 種族 | ガチャ | 得意手、基礎値、覚えられる必殺手（[`battle.md`](./battle.md) 2.12・2.15）。強弱ではなく型の違い |
| 個体値 | ガチャで仲間にした時点で抽選 | 押す力・体格に ±5% |
| レベル | ストーリーの取組に初めて勝つ | 伸ばす値をプレイヤーが選ぶ。上限は章で開く |
| パーツ | ガチャ。合成で強化 | 部位ごとに効く値が決まる |
| 腕 | プレイ | 読み・パリィ・うっちゃり。いちばん大きい差 |

- **主軸はストーリー。** レベルの上限は章で決まり、勝った回数や遊んだ時間では増えない。
- **レアリティは強さの上限を変えない。** ガチャの運で強さが決まらないようにする。レアリティで変わるのは見た目と出やすさだけ。
- **全部を最大にしても、押す力は約1.3倍まで。** 腕の差を装備で埋められないようにする。対戦でも同じ幅で効かせる。

## 補正の合成

[`battle.md`](./battle.md) 3.4 の式を次のように具体化する。

```text
補正   = 個体値倍率 × レベル倍率 × Π(パーツの倍率)  → 値ごとの幅で頭打ち
最終値 = 種族の基礎値 × 補正 + Σ(レベル・パーツの加算値)
```

頭打ちは最終値ではなく補正に掛ける。種族の基礎値（カレーの押す力 1.2 など）はすでに幅の上限近くにあり、最終値で切ると得意な種族ほど育成が効かなくなるため。

| 値 | 個体値 | レベル | パーツの部位 | 補正の幅 |
| --- | --- | --- | --- | --- |
| 押す力 | ±5%（`power`） | 選べる | 手 | 0.9〜1.3 |
| 体格 | ±5%（`hp`） | 選べる | まわし | 0.9〜1.3 |
| 粘り | ─ | 選べる | 足 | 1.0〜1.4 |
| 息の最大 | ─ | 選べる（加算） | 頭 | 100〜130 |
| 息の回復 | ─ | ─ | 頭 | 1.0〜1.2 |
| パリィ受付 | ─ | ─ | 手 | 1.0〜1.1 |
| がっぷり連打係数 | ─ | ─ | 手 | 1.0〜1.1 |
| 熱の時間 | ─ | ─ | まわし | 2.5〜3.0秒 |
| 速さ | ─ | ─ | ─ | 1.0 固定 |

- パリィ受付とがっぷり連打は、[`battle.md`](./battle.md) の推奨幅より狭くしてある。時間の差は読み合いの手応えを大きく変えるうえ、得意手の補正（受付 ×1.3、連打 ×1.25）とも重なるため。
- 速さは [`battle.md`](./battle.md) 5章で未決のため、当面は効かせない。`speed` 列は保持するが、相撲では読まない。
- マイナスの補正を持つパーツは作らない。下振れは個体値だけにする。

## 個体値の換算

DB の `hp` / `power` / `speed` は、今のレアリティ別の値（[`web/battle.md`](../docsArchive/web/battle.md) の「個体値の抽選」）のまま持ち、取組の開始時に倍率へ換算する。

```text
個体値倍率 = 1 + 0.05 × clamp((値 − 基準) / 振れ幅, −1, +1)
```

基準と振れ幅にはレアリティ別の値を使う（HP は12倍）。どのレアリティも ±5% に揃うため、既存の個体はデータ移行なしで使える。

## パーツ

### 枠

| 枠 | 効く値（案） |
| --- | --- |
| まわし | 体格、熱の時間 |
| 頭 | 息の最大、息の回復 |
| 手 | 押す力、パリィ受付、がっぷり連打 |
| 足 | 粘り |
| 必殺手 | 種族が覚えられる必殺手から1つ（[`battle.md`](./battle.md) 2.12） |

- 部位ごとに1つずつ付ける。パーツは手持ちの道具で、うんちくんの間で付け替えられる。
- 1つのパーツの効果は +2〜5% 程度で、合成で最大2倍まで伸びる（[`merge.md`](./merge.md)）。
- 付け替えは取組の外でだけ行う。補正は取組の開始時に1回だけ計算する（[`battle.md`](./battle.md) 3.1）。

### 食事との関係

部位で効く値の候補が決まり、パーツの食品群（激辛・野菜など）で、その中のどの値に効くかが決まる。食品群は直近の食事ログで決まる（例：激辛の手は押す力、野菜の頭は息の回復）。

- 食事ログで決まるのは**種類**だけで、件数は効かない。いろいろ食べると面白いが、たくさん記録しても得はしない（[`game-design.md`](./game-design.md) 3章）。
- [`battle.md`](./battle.md) 3.3 にある「ガンコうんち（硬い日）」のように、便の中身で種族や報酬が変わる仕組みは入れない。良い便・悪い便を選んで記録する動機になるため（[`game-design.md`](./game-design.md) 3章の1）。

## 解放の段階

ストーリー序盤でまだ出てこない仕組み（必殺・熱）に効くパーツは、効果なしにしてグレーで表示する（[`battle.md`](./battle.md) 3.4・3.5）。
