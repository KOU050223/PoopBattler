## 詳細レビュー

### カメラ寿命

`useUserMediaCamera` は開始前の insecure/unsupported を取り違えず、stale な stream は `track.stop()` する。ガチャ画面の unmount と summary でも stop する。映像を state / IndexedDB / Supabase に入れていない。

### 抽選を触らない

`completeBattleAction` のあとで `CompanionshipArStage` が結果を表示するだけ。成功時だけ這い出る。失敗時は「再抽選はできません」。食事ログが無い回は従来の結果カードのまま。

### 軽微

`lastSessionPhotoId` はテストからしか呼ばれていない。完了フローは同等の `lastMealPhotoIdRef` を使っている。挙動は一致している。
