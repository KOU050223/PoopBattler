## 詳細レビュー

### `battle.constants.ts`

`GUARD_DURATION_MS` が 5秒に変更され、`guardCooldownTicks(speed)` が追加されている。式は `round(30 * 20 / Speed)` で、10〜60 tick の丸めも実装どおり。

指摘事項: なし

### `battle-runtime.ts`

ガード自然終了時の cooldown が固定値ではなく `guardCooldownTicks(playerSpeed/enemySpeed)` になっている。Speed は tick 開始時点の combatant から取得しており、既存の通常攻撃周期と同じ扱い。

指摘事項: なし

### `battle-commands.ts`

ガードから `fight` へ戻す、交代で中断する、必殺準備へ入る各経路で、ガードしていた場の一体の Speed を使って cooldown を設定している。交代時は `activeIndex` 更新前の `state.party[state.activeIndex].speed` を使っており、入れ替え先の Speed に誤って依存しない。

指摘事項: なし
