## 詳細レビュー

### build_head_acc.py

- 原点=接地点、-Y正面、メートルの規約は既存 `build_poopm_base.py` と整合。
- プリミティブ生成 → transform_apply → マテリアル付与の流れで、export_apply で確実に焼き込まれる。
- `text_mesh` の "P" はメッシュ変換済み（glTF はフォントを書き出せないため必須）。
- 各GLBは `reset_scene()` してから単独エクスポート。残骸混入なし。

### render_head_acc_preview.py

- `id()` ではなく `o.name` で親子判定（bpy ラッパーはアクセスごとに別物になるため）。初版の実バグをコミット済み。
- メインリグ判定は「スキン済みメッシュを子に持つアーマチュア」。現行GLBの残骸リグを正しく除外できる。

### GLB成果物

- 6種とも静的メッシュのみ・アニメーションなし。ノード名は意味のある名前（`cap_dome` 等）。
- 命名 `head_acc_hat-a.glb` はドキュメントの `head_acc_<id>.glb` とパーツID（`hat-a`）の対応に一致。
