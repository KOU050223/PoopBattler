## 詳細レビュー

### `src/features/poopm/poopm.motion.ts`

#### 変更の意図

各パーツの animate 対象に常に `x` / `y` / `rotate` / `scale*` を載せ、hit は idle と同一オブジェクトを使う。これで hit 専用の横揺れ・回転がパーツ間でバラバラに残らなくなる。

#### 指摘事項

なし。eat は従来どおり部位ごとの反応を残しているが、こちらも `x: 0` を明示しているので hit の残りは eat 経由でも消える。

### `src/features/battle/battle-figure.motion.ts`

#### 変更の意図

被弾シェイクをコンテナの `x` keyframes に集約する。idle / attack は `x: 0`、idle へ戻るときの `x` は duration 0 で即リセットする。

#### 指摘事項

なし。コンテナ揺れ自体は維持されている。

### `src/features/poopm/components/poopm-figure.tsx`

モーション定義を分離し、`initial={false}` を付け、後ろ向きの頭反転を `style.scaleX` から `animate.scaleX` に移して REST の `scaleX: 1` と競合しないようにした。
