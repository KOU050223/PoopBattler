## 概要

Closes #128

仲間化の確定結果を、カメラ重畳のうえで **ぶるぶる → ぶるぶる → ぽん** と見せる。成功は「成功」＋紙吹雪＋重力床に立つ Poopm、失敗は「失敗」だけ。この画面では抽選し直さない。

## 変更内容

- 投げ入れのあとに `shake` フェーズを足し、映像レイヤだけを揺らす
- ぽんで成否を分岐する。揺れ中は文字・紙吹雪・うんちくんを出さない
- 成功時だけ、投げ入れ先と同じ点に `PoopmFigure` を立てる（加速度の重力。取れなければ画面上が上）
- カメラ拒否時は静止背景を同じ拍で揺らす
- 演出の拍は [`docs/companionship-crawl.md`](../companionship-crawl.md)
