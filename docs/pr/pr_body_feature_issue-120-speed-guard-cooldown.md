## 概要

Closes #120

`まもれ` の持続を5秒固定にし、ガード終了後のクールを場の一体の Speed に応じた反比例式へ変更しました。プレイヤーと敵のガードで同じ持続時間・同じクール式を使います。

## 変更内容

- `GUARD_DURATION_MS` を 5秒へ変更
- `guardCooldownTicks(speed)` を追加し、`round(30 × 20 / Speed)` を 10〜60 tick に丸める仕様を実装
- ガード自然終了、`fight` への戻し、交代、必殺準備による中断で、ガードしていた場の一体の Speed を使ってクールを設定
- 敵ガードの自然終了も同じ Speed 式でクールへ入るよう更新
- 受け入れ条件に対応するテストと `docs/battle.md` を更新
