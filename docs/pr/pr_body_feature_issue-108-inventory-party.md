## 概要

Closes #108

図鑑画面をインベントリに置き換え、所持キャラから先発3体を編成できるようにします。バトル開始は選んだ `user_characters.id` だけを渡し、HP / Power / Speed はサーバーが確定します。

## 変更内容

- `/collection` の見出し・説明・ボトムナビを「インベントリ」に変更（ルートは互換のため残置）
- 上部に先発3枠、下部に所持リスト。枠を選んでからリストで入れ替える
- 先発中はリスト側でも「選出中」と出し、空き枠はレンタルと分かるようにする
- `startBattleAction` が `userCharacterIds` を受け取る。空なら従来どおり新しい順の自動選出
- 不足分は既存どおり `normal` レンタル。他人の ID は RPC が採用しない
