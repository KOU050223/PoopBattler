# バトルシステム改善 — 「ローテーション綱引き」システムへの転換（草案）

## 概要・背景
現状のバトルシステムにおける「介入の意味が薄く、簡単すぎてつまらない」「ベンチの2体が手持ち無沙汰になる」という課題を解消するためのシステム刷新案です。
従来のアクションRPG的な「コマンド選択とHPの削り合い」を廃止し、排便という行為に直結する**「綱引き（押し出し）」**と**「陣形のローテーション」**をコアにした新システムへ移行します。

設計コンセプト：**「ローテーションで耐え凌ぎ、ここぞの踏ん張り（全力シェイク）で便器に叩き落とす」**

---

## 新システム：ローテーション綱引きバトルの基本仕様

### 1. 「HPの削り合い」から「ポジションの奪い合い（綱引き）」へ
* 画面中央に綱（あるいは押し合う境界線）があり、オートでジリジリと引っ張り合います。
* 敵を画面の右端（便器）まで引きずり落とせば勝利。左端まで引かれると敗北。
* 見た目の直感性が高く、「今どちらが勝っているか」が一目でわかります。

### 2. 3体縦並びの「ローテーション」
* 選出した3体のうんちくんはベンチに下がるのではなく、**3体全員が縦一列に並んで同時に綱を引きます**。
* **先頭（フロント）：** メインの踏ん張り役。100%の力を出し、敵からの反動（スタミナ減少）を全て引き受ける。
* **後衛（バック2体）：** サポート役。先頭を後ろからアシストしつつ、消費したスタミナを回復する。
* **プレイヤーの操作①：** 画面のタップ（またはスワイプ）で、先頭のキャラをクルクルと入れ替える（ローテーション）。敵の強攻撃に合わせて耐久力の高いキャラを先頭に出すなどの「陣形タクティクス」が発生します。

### 3. 属性×ポジションによる「スキル」の発動
個体の3ステータス（引く力・防御力・持続力）に加え、属性ごとにポジションに応じたスキルが発動します。
* **先頭時（メインスキル）：** 例）水属性＝相手のスタミナを削る、木属性＝引かれる力を激減させる
* **後衛時（サポートスキル）：** 例）炎属性＝先頭の引く力を底上げ、雷属性＝応援ゲージが溜まりやすくなる
これにより、「誰を先頭にして、誰を後ろに置くか」という編成のパズル要素が生まれます。

### 4. 逆転の超絶カウンター「全力シェイク」
* **プレイヤーの操作②：** ピンチの時やゲージMAX時に、画面に「踏ん張れ！！！」の文字が出現。
* ここでプレイヤーがスマホを全力でシェイク（＝物理的な踏ん張り）すると、先頭キャラが覚醒（ゾーン状態）。一時的に猛烈な力で綱を引き込み、一発逆転を狙えます。

## プレイ体験の2層構造（NPC戦とPVP戦）

本システムは、日常のプレイと友人との集まりで体験の質を明確に分けます。

### 日常のトイレ（NPC戦）
* **目的：** 記録のついでにマイペースに遊ぶ。キャラの収集と育成（仕込み）。
* **体験：** 敵の属性や動きに合わせて陣形をローテーションし、有利な状況を作り出す。操作は片手でサクッと完結。

### 友達との集まり（リアルタイムPVP戦）
* **目的：** 育てたうんちくんを持ち寄り、顔を突き合わせて遊ぶパーティゲーム。
* **体験：** Supabase Realtimeを活用。お互いに陣形を回して牽制し合い、勝負所で「いけー！！」と叫びながら全力でスマホを振る、eスポーツ的な熱狂を生み出します。

## 期待できる効果・実装メリット
* **UI/操作の極限のシンプル化：** バトル中の操作は「入れ替え」と「振る」のみ。コマンドボタンを廃止し、画面全体をダイナミックな演出（キャラの汗、綱の揺れ）に使えます。
* **全キャラに価値が生まれる：** ステータスが低くても「強力なサポートスキル持ち」として後衛で活躍できます。
* **工数の最適化：** 状態異常や複雑なダメージ計算式、3Dの派手なカメラワークなどが不要。フロントエンドのCSSアニメーション（DOM要素の振動など）とシンプルな1次元の数値計算で圧倒的なダイナミズムを作れます。
