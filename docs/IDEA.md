# 「踏ん張れ！ブリュレイド！！」

## 概要

排便そのものをゲーム体験に変えることで、**食事と排便のデータを自然に継続記録できるモバイルWebアプリ**。

トイレでアプリを開くと、「うんちくん」が敵として登場し、3体パーティのオートバトルが始まる。撃破後に排便状態を記録し、食事ログがあれば、倒したうんちくんを便器から這い出させて仲間にできる。

> **うんちくんと戦って仲間を集めていたら、いつの間にか食事と排便のライフログが蓄積されている**

- プラットフォームはモバイルWeb。ストア不要で、ホーム画面への追加（PWA）に対応する。日本語・英語の2言語。
- 匿名サインインで即開始。Googleアカウント連携で別端末へ引き継げる。
- タイトル画面でも、スマホを振るとうんちくんが寄ってくる。
- 実装とデータの詳細は [`architecture.md`](./architecture.md)。ここは企画と体験の整理だけ。

## ゲームループ

```text
トイレに行く
↓
アプリを開く
↓
バトル開始（敵はサーバーが抽選）
↓
3体パーティのオートバトル
↓
撃破 → 排便状態を記録
↓
食事を記録（ここでも記録できる。スキップ可）
↓
食事ログがあればガチャへ
↓
カメラを便器へ向け、食事写真を投げ入れる
↓
抽選に当たれば、倒したうんちくんが這い出てくる
↓
図鑑・パーティ編成へ
↓
次のトイレへ
```

食事記録は必須ではない。0件でもバトルと排便記録は成立するが、仲間化の抽選自体は行われない。

## 排便ログ

撃破直後に選択式で記録する。文章入力は求めない。

- 硬さ（1〜7）、量、色、出しやすさ、症状（強くいきんだ・残便感・腹痛・急な便意）

## 食事ログ

「食事」タブからいつでも記録できる。写真（その場撮影またはファイル選択）＋食品群タグ＋任意メモ。**写真本体は端末内のIndexedDBに置き、サーバーへは送信しない。**

バトル完了前にも同じフォームが出て、その場で食事を記録できる。スキップしてもバトルは完了する。

食事ログは仲間化の鍵で、**累計件数が多いほど抽選確率が上がる**。


| 食事ログの累計 | 仲間化確率 |
| ------- | ----- |
| 0件      | 抽選なし  |
| 1件      | 50%   |
| 2件      | 75%   |
| 3件      | 85%   |
| 4件以上    | 90%   |


## 仲間化ガチャ

食事ログを紐付けてバトルを完了すると、ガチャが始まる。

1. カメラが開き、便器へスマホを向ける。
2. 端末内の物体検出が便器を認識し、投げ入れ先を合わせる。検出できなくてもタップで投げ入れ先を決められる。
3. 食事写真をスワイプで便器へ投げ入れる。
4. サーバー側で確定した抽選結果に応じて、倒したうんちくんが重力に沿って便器から這い出てくる。

映像やフレームは保存・送信しない。演出の向きと拍は [`companionship-crawl.md`](./companionship-crawl.md)。

## コレクションと記録

- **図鑑**: 仲間にしたうんちくんの一覧。ここでバトルに出す3体を編成する。見た目は種族の色＋個体ごとの頭・目・口で決まる（[`poopm.md`](./poopm.md)）。バトルとガチャは3Dで描画する。
- **記録**: バトルと排便ログの履歴。
- **レポート**: 週次の排便レポート（後述）。

## プレミアム

ゲーム部分は無料で提供し、蓄積したデータの分析を有料にする。


|                    | 無料         | プレミアム |
| ------------------ | ---------- | ----- |
| バトル・収集・ガチャ・食事/排便記録 | ○          | ○     |
| 週次レポート             | 見本のティーザー表示 | ○     |


週次レポートの内容は、排便回数・記録日数・平均の硬さ・整っている便の割合、硬さ/量/色/出しやすさの内訳、曜日・時間帯、直近4週間との比較、食品群との傾向。

- **購入前にGoogleアカウント連携を必須にする。** 匿名のままだと端末を変えたときに権利を復旧できないため。
- バトルや収集は有料にしない。遊べなければ記録が溜まらず、レポートも成立しないため。

## 一言で説明すると

> **トイレでうんちくんと戦って仲間を集める。遊んでいるだけで食事と排便のライフログが貯まる、うんちバトル収集アプリ。**
