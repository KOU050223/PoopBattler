# 「ふんばれ！ブリュレイド！！」

## 概要

食事と排便のデータを自然に継続記録できるアプリ。**トイレにいる間に1分のレースを遊び、終わったら記録する。** 記録を続けた日数でうんちくんが育つ。

> **トイレの時間がレースになる。続けるほど育つ、うんちレース収集アプリ。**

- iOS / Android アプリと、ブラウザ版（Expo web、PWA対応）。日本語・英語の2言語。構成は [`native/web-retirement-plan.md`](./native/web-retirement-plan.md)。
- 匿名サインインで即開始。Googleアカウント連携で別端末へ引き継げる。
- ループの設計方針と不正対策の根拠は [`game-design.md`](./game-design.md)（正本）。ここは企画と体験の整理だけ。

## ゲームループ

```text
トイレ（1分）
 レースを遊ぶ → 排便・食事をタップで記録
↓
翌日以降、最初にアプリを開いたとき
 前日までの記録を反映 → 相棒にポイントを振る、ガチャの石をもらう
```

- 育成に効くのは記録の1日分だけ。何回記録しても増えず、レースの着順も関係しない。
- 「出なかった」日も1日の記録として数える。便の中身では何も変えない。
- 後入力や不自然な記録の日は、ポイントと石を減らす。
- 数えるのは通算の記録日数で、途切れてもペナルティはない。

## 排便ログ

トイレで選択式で記録する。文章入力は求めない。

- 硬さ（1〜7）、量、色、出しやすさ、症状（強くいきんだ・残便感・腹痛・急な便意）
- 「出なかった」も記録できる。

記録時刻は自動付与で編集不可。後入力は同日のみで、フラグを付けて集計では重みを下げる。

## 食事ログ

「食事」タブからいつでも記録できる。写真（その場撮影またはファイル選択）＋食品群タグ＋任意メモ。**写真本体は端末内に置き、サーバーへは送信しない。**

食事ログは育成になる。1日1回分で頭打ちで、食品群で伸びる値が決まる。いろいろ食べると面白い動機にはなるが、記録の回数を増やす動機にはならない設計にする。

## 育成とゲーム

メインは**レース**、**うんちくん相撲**（1対1のリアルタイム、相手を便器まで押し出したら勝ち。[`battle.md`](./battle.md)）はサブモード。強さの決まり方とパーツは [`parts.md`](./parts.md)、レベルは [`level.md`](./level.md)、合成は [`merge.md`](./merge.md)。

- 育つのはその日の**相棒1体**。ステータス（体力・パワー・技術、案）はどのゲームでも共通。
- パーツは頭・手・足の3部位。同じパーツでもゲームごとに効く値が違う。相撲には別に必殺手の枠がある。
- 重複したパーツやうんちくんは、ベースのパーツを決めてまとめて合成し、パーツを強化する。
- 対戦ではレベルを揃え、振り分けの比率・個体値・パーツで差をつける。

## 現行実装との差分

実装は旧ループ（トイレでHP制オートバトル → 排便記録 → 食事ログの件数に応じた仲間化ガチャ）のまま。ガチャの仕様は [`web-spec.md`](../docsArchive/web/web-spec.md)、演出は [`companionship-crawl.md`](../docsArchive/web/companionship-crawl.md)、収集と図鑑は [`poopm-3d.md`](../docsArchive/poopm-3d.md) を参照。新ループでは、食事ログ件数による仲間化の抽選をやめ、記録でもらえる石で引くガチャに置き換える。

## ガチャと撮影

- **ガチャの演出**: 旧ループの仲間化演出（うんちくんが便器から這い出てくる）を、ガチャの結果発表として残す（[`companionship-crawl.md`](../docsArchive/web/companionship-crawl.md)）。
- **撮影**: 旧ガチャのAR（カメラ越しに便器を検出する部分）は、ポケモンGOのような写真撮影機能として残す。カメラ越しの景色に手持ちのうんちくんを置いて撮る。写真は食事写真と同じく端末に置き、サーバーへは送らない。

## コレクションと記録

- **図鑑**: 仲間にしたうんちくんの一覧と編成。見た目は種族の色＋個体ごとの頭・目・口で決まる（[`poopm-3d.md`](../docsArchive/poopm-3d.md)）。
- **記録**: 排便・食事ログと遊んだ履歴。
- **レポート**: 週次の排便レポート。

## プレミアム

ゲーム部分は無料で提供し、蓄積したデータの分析を有料にする。

|                    | 無料         | プレミアム |
| ------------------ | ---------- | ----- |
| ゲーム・食事/排便記録 | ○          | ○     |
| 週次レポート             | 見本のティーザー表示 | ○     |

週次レポートの内容は、排便回数・記録日数・平均の硬さ・整っている便の割合、硬さ/量/色/出しやすさの内訳、曜日・時間帯、直近4週間との比較、食品群との傾向。信頼度が低い記録は集計と受診用サマリーで重みを下げる。

- **購入前にGoogleアカウント連携を必須にする。** 匿名のままだと端末を変えたときに権利を復旧できないため。
- ゲーム部分は有料にしない。遊べなければ記録が溜まらず、レポートも成立しないため。
- データのBtoB活用（集計インサイト提供・協業）は規模が出たあとの将来オプション。個別レコードは売らない。詳細は [`business-plan.md`](./business-plan.md)。

## 一言で説明すると

> **トイレで1分レースして、記録する。続けるほどうんちくんが育つ。遊んでいるだけで食事と排便のライフログが貯まる、うんち収集アプリ。**
