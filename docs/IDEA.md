# 「踏ん張れ！ブリュレイド！！」

## 概要

食事と排便のデータを自然に継続記録できるモバイルWebアプリ。**トイレでは短く記録するだけ**で、記録するとゲームの素材（ドロップ）が手に入る。ゲーム本編は**寝る前**に遊ぶ。

> **記録がゲームの素材になる。毎晩の習慣になる、うんちバトル収集アプリ。**

- プラットフォームはモバイルWeb。ストア不要で、ホーム画面への追加（PWA）に対応する。日本語・英語の2言語。
- 匿名サインインで即開始。Googleアカウント連携で別端末へ引き継げる。
- 実装とデータの詳細は [`architecture.md`](../docsArchive/web/architecture.md)。ここは企画と体験の整理だけ。
- ループの設計方針と不正対策の根拠は [`game-design.md`](./game-design.md)（正本）。

## ゲームループ

```text
トイレ（5〜10秒）
 排便・食事をタップで記録 → ドロップを1つ獲得（短い演出のみ）
↓
寝る前（1回数分）
 たまったドロップで、孵化・育成・バトルを遊ぶ
↓
翌日も記録したくなる仕掛け（孵化待ち・翌日イベントなど）
```

- ドロップ例：うんちくんのたまご、パーツ、対戦相手の種。属性は直近の食事から決まる。
- 「出なかった」日も記録でき、報酬は同じ。報酬は便の中身に連動させない。
- 記録がうまくいった日はガチャ3回、後入力や不自然な記録の日は1回。何回記録しても増えない。

トイレでは長居させないことが前提。ゲームは寝る前に分けるので、1日のプレイ時間上限と、就寝前の終了を促す演出を入れる。

## 排便ログ

トイレで選択式で記録する。文章入力は求めない。

- 硬さ（1〜7）、量、色、出しやすさ、症状（強くいきんだ・残便感・腹痛・急な便意）
- 「出なかった」も記録できる。

記録時刻は自動付与で編集不可。後入力は同日のみで、フラグを付けて集計では重みを下げる。

## 食事ログ

「食事」タブからいつでも記録できる。写真（その場撮影またはファイル選択）＋食品群タグ＋任意メモ。**写真本体は端末内のIndexedDBに置き、サーバーへは送信しない。**

食事ログはドロップの属性を決める。いろいろ食べると面白い動機にはなるが、便の回数を増やす動機にはならない設計にする。

## バトルと育成

寝る前に遊ぶ。バトルは**うんちくん相撲**（1対1のリアルタイム、片手の指1本、相手を便器まで押し出したら勝ち）。仕様は [`battle.md`](./battle.md)。強さの決まり方とパーツは [`parts.md`](./parts.md)、レベルは [`level.md`](./level.md)、合成は [`merge.md`](./merge.md)。

- 強さはストーリーを進めると伸びる。力士はストーリーの取組に初めて勝つとレベルが上がり、伸ばす値を選べる。上限は章で開く。未クリアの取組に挑めるのは記録した日だけ。
- パーツはまわし・頭・手・足の4部位と必殺手。必殺手は種族ごとに覚えられるものが違う。
- 重複したパーツやうんちくんは、ベースのパーツを決めてまとめて合成し、パーツを強化する。
- 強さの幅は約1.3倍までで、腕の差を超えない。対戦でも同じ。
- バトルの難しさは、ストーリー序盤はゆっくり・必殺なし、終盤と対戦は試作の「本気」くらいを目安に段階的に上げる。
- 連続報酬は便の回数ではなく**記録を続けた日数**に連動させる。

## 現行実装との差分

実装は旧ループ（トイレでHP制オートバトル → 排便記録 → 食事ログの件数に応じた仲間化ガチャ）のまま。ガチャの仕様は [`web-spec.md`](../docsArchive/web/web-spec.md)、演出は [`companionship-crawl.md`](../docsArchive/web/companionship-crawl.md)、収集と図鑑は [`poopm-3d.md`](../docsArchive/poopm-3d.md) を参照。新ループでは、食事ログ件数による仲間化の抽選をやめ、記録で引けるガチャに置き換える。

## ガチャと撮影

- **ガチャの演出**: 旧ループの仲間化演出（うんちくんが便器から這い出てくる）を、ガチャの結果発表として残す（[`companionship-crawl.md`](../docsArchive/web/companionship-crawl.md)）。
- **撮影**: 旧ガチャのAR（カメラ越しに便器を検出する部分）は、ポケモンGOのような写真撮影機能として残す。カメラ越しの景色に手持ちのうんちくんを置いて撮る。写真は食事写真と同じく端末に置き、サーバーへは送らない。

## コレクションと記録

- **図鑑**: 仲間にしたうんちくんの一覧と編成。見た目は種族の色＋個体ごとの頭・目・口で決まる（[`poopm-3d.md`](../docsArchive/poopm-3d.md)）。
- **記録**: 排便・食事ログと遊んだ履歴。
- **レポート**: 週次の排便レポート。

## プレミアム

ゲーム部分は無料で提供し、蓄積したデータの分析を有料にする。

|                    | 無料         | プレミアム |
| ------------------ | ---------- | ----- |
| ゲーム・食事/排便記録 | ○          | ○     |
| 週次レポート             | 見本のティーザー表示 | ○     |

週次レポートの内容は、排便回数・記録日数・平均の硬さ・整っている便の割合、硬さ/量/色/出しやすさの内訳、曜日・時間帯、直近4週間との比較、食品群との傾向。信頼度が低い記録は集計と受診用サマリーで重みを下げる。

- **購入前にGoogleアカウント連携を必須にする。** 匿名のままだと端末を変えたときに権利を復旧できないため。
- ゲーム部分は有料にしない。遊べなければ記録が溜まらず、レポートも成立しないため。
- データのBtoB活用（集計インサイト提供・協業）は規模が出たあとの将来オプション。個別レコードは売らない。詳細は [`business-plan.md`](./business-plan.md)。

## 一言で説明すると

> **トイレでは記録するだけ。寝る前にうんちくんを育てて戦う。遊んでいるだけで食事と排便のライフログが貯まる、うんちバトル収集アプリ。**
