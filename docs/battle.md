# バトル

ループと戦闘後ガチャは [`IDEA.md`](./IDEA.md)、永続化と敵生成は [`architecture.md`](./architecture.md)。ここは戦闘のルールだけ。

トイレで画面を見続けられない。通常攻撃は自動、プレイヤーはたまに指示するだけ（妖怪ウォッチの指示に近い）。踏ん張りは**必殺の準備**に使う。

長さの目安はタイムアップ約90秒。通常攻撃は間欠なので、無操作だと時間切れまで残ることが多い。タイムアップ時は残HPで勝敗を決めてよい。

## パーティ

3体選出、**場に出るのは1体、残り2体はベンチ**。場の一体だけが攻撃・ガード・必殺する。

控えは場に出るまでダメージを受けない。入れ替えは約1秒硬直。やられたらベンチ先頭が自動で出る。3体とも倒されたら敗北。必殺ゲージは交代で空にする。

戦闘前に3体を決める。未所持が多い序盤は空きを `normal` のレンタル1体で埋めてよい。

## 操作

画面下は `たたかえ` / `まもれ` / `必殺` と、控え2体。

| 入力 | 動き |
| --- | --- |
| たたかえ（既定） | 場の一体が自動で殴る。タップ不要。味方・敵とも約5ティックに1回、当たるかは半々で、1発は重め |
| まもれ | 約10秒、被ダメ半減＋自分はほぼ殴らない。その後クール（約15秒）。全カットにしない |
| 必殺 | ゲージ満タンで押す → 約3秒の準備。その間だけ踏ん張ると発射。妖怪ウォッチの必殺技と同じ役割 |
| 交代 | 控えと入れ替える。連打で最適タイプに張り付かせないための硬直あり |

敵も同じ3行動。必殺の予告は約2秒大きく出す。それ以上の読み合いは作らない。

ゲージは時間経過で溜まる。

## ステータス（個体ごと）

HP / Power / Speed は**種族ではなく個体**に付く（`user_characters` の行）。
同じ「カレーうんちくん」でも、自分の1体と他人の1体、自分の2体目で数値が違ってよい。

| 列 | 戦闘での意味 |
| --- | --- |
| HP | 開幕の最大HP。HPバーの分母もこの値 |
| Power | 通常攻撃の基礎ダメージ。タイプ補正とガードはこの値に掛かる |
| Speed | 通常攻撃の待ちティック |

**必殺は Power に乗せない。** 基礎4×倍率10のまま据え置く。Power を掛けると
倍率10がそのまま乗り、通常攻撃との差が跳ね上がるため。

Speed から待ちティックを出す式は反比例で、基準 Speed 20 がちょうど5ティック。

```text
待ちティック = round(5 × 20 / Speed)   （2〜10 に丸める）
```

上下限を置くのは、極端な個体で1ティック連打や事実上の無攻撃にしないため。

ステータスの出所は経路で分かれる。

| 経路 | 出所 |
| --- | --- |
| 所持して選出した個体 | その `user_characters` 行。開始時にサーバーがスナップショットへ載せる |
| レンタル | コード定数の初期値。所有行を作らず、勝っても育たない |
| 敵 | バトル開始時にサーバーが決めてスナップショットへ載せる。マスターの列にはしない |

クライアントは3値を指定できない。開始時に渡せるのは**自分の所持個体の行ID**だけで、
値そのものはサーバーが `user_characters` から読む。成長も definer RPC だけが書く。

初期値は仲間化成功時に振る。基準は共通で、レアリティは振れ幅だけを変える
（common ±5 〜 legendary ±20、HPは4倍幅）。common でも legendary の値域に
届きうるし、その逆もある。勝利のたびに HP +6 / Power +1 / Speed +1 を1回書く。

タイムアップ時の勝敗は、**残HPの割合**で比べる（生の合計ではない）。個体ごとに
最大HPが違うので、合計値で比べると個体値がそのまま勝敗の下駄になるため。

## タイプ

属性は既存の7種を戦闘でも使う。3体出せるのですくみは畳まない。暗記はさせず、場の一体と敵の関係を有利・等倍・不利の3色で出す。

6属性は輪。時計回りに隣2つへ強く（1.5）、反対2つへ弱い（0.75）。等倍は 1.0。

```text
激辛 → 肉 → 野菜 → 乳 → 甘 → カレー →（激辛）
```

| 攻撃側 | 有利 | 不利 |
| --- | --- | --- |
| 激辛 `spicy` | 肉、野菜 | 甘、カレー |
| 肉 `meat` | 野菜、乳 | カレー、激辛 |
| 野菜 `vegetable` | 乳、甘 | 激辛、肉 |
| 乳 `dairy` | 甘、カレー | 肉、野菜 |
| 甘 `sweet` | カレー、激辛 | 野菜、乳 |
| カレー `curry` | 激辛、肉 | 乳、甘 |
| 無 `normal` | なし | なし |

`normal` は与えるのも受けるのも等倍。敵タイプは開始時のランダムのまま。食事写真は戦闘後のガチャにだけ使い、戦闘中のタイプは変えない。

## やらないこと

コンボ入力、フレーム回避、パーティ3体同時攻撃、状態異常。
