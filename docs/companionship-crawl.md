# 仲間化・reveal 演出

戦闘後ガチャの **reveal**。抽選・投げ入れ・便器検出は既存のまま。投げ入れのあと、カメラを揺らして便器が震えているように見せ、**ぶるぶる → ぶるぶる → ぽん** で成否を出す。

ループ全体は [`IDEA.md`](./IDEA.md) §6、抽選の確定は [`architecture.md`](./architecture.md)、見た目パーツは [`poopm.md`](./poopm.md)。Issue は [#128](https://github.com/KOU050223/PoopBattler/issues/128)。


## 空間

WebXR / hit-test は使わない。重力が取れるときは、その上に垂直な仮床の上に `PoopmFigure` を立てる（ビルボード。足が床、体の上が世界の上、ヨーだけカメラ向き）。取れないときは画面上が上。

出現点は投げ入れと同じ。便器 `hit` なら座面寄り、なければタップ、それもなければ `{ x: 50, y: 72 }`。bbox は座標だけ。

揺れは映像レイヤ（カメラまたは静止背景）を短く平行移動・微小回転させる。便器メッシュは動かさない。タイトルと「結果を見る」は揺らさない。

この画面でモーション許可は新たに出さない。Three.js / 新メッシュ / GLB は足さない。

## 共通（ぶるぶる → ぽん）

投げ入れ（約 0.9s）のあと。成否で揺れを変えない。`prefers-reduced-motion` なら揺れを省略し、ぽん相当を即出す。

| 拍 | 目安 | 画面 |
| --- | --- | --- |
| ぶる | 0.0–0.35s | 映像が小刻みに揺れる |
| ぶる | 0.35–0.70s | 同じ揺れをもう一拍。少し大きくしてよい |
| ぽん | 0.70s | 揺れが止まる。ここで成否が分岐する |

ぽんより前に文字・紙吹雪・うんちくんは出さない。

## 成功（ぽん）

取得キャラがあるときだけ。レア別演出は作らない。

同時に出すのは次の3つ。

- 文字「成功」
- 紙吹雪（画面内の短い CSS。絵文字の雨にはしない）
- 出現点にうんちくんが直立で出る（`idle`。段階出現なし）

再抽選しない旨は、既存どおり画面上の説明に残す。

## 失敗（ぽん）

食事ログあり・未取得のとき。出すのは文字「失敗」だけ。紙吹雪・うんちくん・成功と同じポップは出さない。

この画面で抽選し直さない。スキップは既存の「結果を見る」。

## フォールバック

カメラとモーションは独立に落ちる（[`architecture.md`](./architecture.md)）。

| 欠けるもの | 動き |
| --- | --- |
| カメラ拒否・非対応 | 静止背景を同じ拍で揺らす。ぽん以降は同じ |
| 重力が取れない | 画面上が上。成功時の立ち位置だけ変わる |
| 両方ダメ | 静止背景 + 画面下方向の直立出現。結果の文字は必ず出す |
| 便器 bbox なし | 投げ入れ先と同じ点 |

## 対象外

Poopm の新描画、便器モデル追加、投げ入れの作り直し、ARKit / ARCore / WebXR、便器の向き推定、コレクション画面の 3D 化。WebXR の可否は [#130](https://github.com/KOU050223/PoopBattler/issues/130)。
